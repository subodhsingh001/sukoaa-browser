SUKOAA BROWSER 0.7.1-beta.1 — SITE PERMISSIONS
Prepared 23 October 2026. Internal preview; public-release clearance is pending.

WHERE TO FIND IT
Desktop: Menu > Site permissions.
Android: Browser tools > Site permissions · camera, microphone, location.
Open an HTTPS website, then choose Ask, Allow or Block for each permission.
Supported requests also show a prompt automatically. Reset all returns to Ask.

Normal approvals may be saved or limited to the browser session. Private
approvals remain in memory and disappear when the private tab closes.
Changing settings reloads affected tabs to stop existing capture/watchers.
On Android, normal permission changes also notify the other browser view to
reload normal tabs; private permission changes remain local to the private tab.
Android asks for system permissions after site approval and links to Android
app settings. OS permissions are app-wide and remain separate from private
site decisions. Normal audio playback does not require microphone permission.
Cross-origin embedded requests and screen sharing remain unsupported.
Desktop location availability depends on the configured engine/OS provider;
allowing a site does not by itself supply a location service.
