Private & clean testing

Private tabs use separate cookies/site storage, no disk profile, disabled HTTP cache and no extensions. They are excluded from history and session restore.

A hard reload bypasses HTTP cached files; service workers/site storage can still serve their own data. Clean test starts an isolated session. Neither hides your activity from websites or your network.

Page performance

Blocks downloaded images and media on this tab, then reloads. Useful for text-heavy browsing on slow connections; images and videos will be missing. Embedded data images can remain.

Open a page to view load timing.

No comparative benchmark has established that Sukoaa is faster than Chrome, Brave, Edge or Firefox.

Extensions

Load compatible unpacked extensions from a folder containing manifest.json. Chrome Web Store install and CRX files are unsupported. Chrome API support is partial; toolbar actions are offered only when a popup/options page is declared. Keep the folder in place.

Extensions run only in normal tabs. Review requested access before adding. Reload existing pages after adding/removing content scripts.
