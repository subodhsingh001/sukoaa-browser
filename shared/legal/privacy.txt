PRIVACY NOTICE — PREVIEW CANDIDATE
Effective 22 October 2026

Sukoaa is a working name. This candidate is not approved for public launch. The publisher's public contact and final distribution website are not configured; they must be supplied before publication. This notice describes the code in this candidate, not every website, extension or engine service.

LOCAL DATA
Normal browsing history, bookmarks, settings and desktop session URLs are kept in the device profile. Websites can store cookies, cache, localStorage and other site data there. Extension folder paths and installed add-on state can also be retained. Android normal WebView and advanced Gecko pages use separate stores. The app does not provide encrypted password storage or account sync. OS/device administrators may access local files. Android application backup is disabled; desktop backup tools may copy the profile.

PRIVATE BROWSING
Private pages are excluded from the application's persistent history and session restore. Desktop private partitions are temporary, with HTTP cache disabled and cleanup on close. Android private Gecko sessions use private contexts; a popup can share its opener's context, which is cleared after the last related tab closes. Downloads/bookmarks deliberately saved, OS records, external applications, the keyboard, websites, account activity and network-provider records are not erased by closing a private tab. Private browsing is not a VPN or anonymity service. Crash/power-loss cleanup and physical devices still need verification.

NETWORK CONNECTIONS
Websites and selected search providers receive normal navigation/search requests, including IP address and browser request metadata. Filter updates, when requested by you, contact easylist.to and raw.githubusercontent.com; these hosts can see network metadata. Desktop scriptlet downloads are pinned to a reviewed immutable Ghostery mirror revision and checked against a bundled SHA-256 digest. Changing that executable scriptlet revision requires a reviewed application release. EasyList/EasyPrivacy data updates remain user initiated. New application/engine binaries do not update automatically. Android WebView/Gecko security and add-on services may contact their upstream providers, including Mozilla/Google. Extensions and visited sites may contact their own services. No custom analytics, advertising SDK, account server or crash-upload endpoint is configured by the Sukoaa application. This is not a claim that engines, websites, providers or installed extensions send no data.

PERMISSIONS AND FILES
Camera, microphone and location access are denied until you approve each secure website. Menu > Site permissions provides Ask, Allow and Block, with reset controls. Normal saved decisions persist locally; session approvals remain in memory. Private decisions are held only for the private tab and discarded on close. Android also requests the corresponding system permission; approximate location is supported when the OS grants it. Camera/microphone streams and coordinates can be sent by the approved website to its service; review that site's policy. Sukoaa does not collect a separate copy for telemetry. Changing site access reloads affected pages to stop existing capture/location watchers. Embedded cross-origin requests and other unsupported permissions remain blocked. Desktop location availability depends on the engine's configured provider and the OS; permission approval alone does not guarantee a position. Notifications remain denied; fullscreen has its own permission/gesture checks. File upload uses the operating-system picker. Downloads require your action/confirmation and remain in your chosen location until removed there. Android sharing hands the selected page to an external app. Copy-link actions use the OS clipboard. Desktop unpacked extensions and Android signed Firefox-compatible add-ons can access sites according to their permissions; review each author and privacy policy. Private extensions are disabled. Optional Android USB inspection gives your authorized computer page access until disabled/app exit.

YOUR CONTROLS
History entries can be deleted individually. Clear-data controls remove the selected local history/cookies/cache/session data; advanced Gecko has separate clearing controls. Deleting history does not delete downloaded files, bookmarks, remote account history or all OS records. You can pause protection for a site, remove extensions and delete the application profile after closing the app. Filter-update requests are user initiated. Application update checks are disabled in this build. If a release owner configures a verified channel, manual checks (and optional owner-enabled startup checks) contact the configured HTTPS release origin; that server sees ordinary network metadata such as your IP address. Downloads are checked against signed metadata and, on Windows, the configured publisher certificate. No installer runs automatically. The highest valid signed release version observed is stored locally to reject rollback metadata.

SUPPORT AND CHANGES
Public contact: NOT CONFIGURED — public-release blocker. Before a public release, replace this with a real support/privacy contact and publish the final policy at an HTTPS URL. Update this notice before enabling analytics, sync, accounts, crash upload, a binary updater or other new data flows. No GDPR/DPDP or other worldwide regulatory certification is claimed.
