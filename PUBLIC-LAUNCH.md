# Sukoaa public release status — BLOCKED

Sukoaa replaces the Aegis working name at the owner's request. The visible branding and project-authored S shield are changed in source. Limited web screening is complete; a qualified trademark/logo review is not. No domain or trademark is registered by these changes.

This is an internal beta preparation, not a publicly cleared product. Use release/BUILD-SIGN-RELEASE.md, SECURITY.md, LICENSE-SCOPE.md and compliance/ for the process. Android retains com.subo.aegis.next for update compatibility. Existing preview users need the same signing identity to update in place. The old Java namespace, profile names and asset filenames are compatibility internals, not the public brand.

Windows publisher signing, complete source obligations, physical-device testing and a public support/privacy contact remain unresolved. The privacy HTML has an explicit missing-contact marker and has not been deployed publicly.
