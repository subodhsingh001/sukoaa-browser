Optional unpacked extension example. It is NOT installed automatically.
In desktop Aegis open Menu > Tools & extensions > Add unpacked extension,
select this page-lens folder, review access and choose Add extension.
Reload a normal HTTP/HTTPS page. A Page Lens button appears bottom-right.
It displays approximate visible word count, reading time and viewport size.
It makes no network requests and stores no data. It is excluded from private tabs.
Remove it from Tools & extensions and reload pages to remove existing buttons.
