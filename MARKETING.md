# Candidate description — factual wording only

Working-name browser preview for Windows, Linux and Android, with local request filtering, private sessions, local history controls and browsing/developer conveniences. Desktop includes keyboard zoom, fit width, Lite mode, responsive inspection and a searchable tab list. Android uses WebView for regular pages and GeckoView for private/add-on sessions. Engine and extension capabilities differ across platforms.

Headless Linux regressions cover selected private-history, cookie, cache, tab, zoom and developer scenarios. Android compilation/JVM tests are not physical-device tests. Windows native launch, real desktop GPU/DPI behavior, Android device behavior and live MSN/YouTube compatibility are not certified.

Do not claim fastest, safest, blocks all ads, guaranteed YouTube blocking, no network traffic, anonymity, audited security, full Chrome extension support, legal clearance, trademark clearance or store approval. Do not quote synthetic page-load ratios as cross-browser performance results. No release under the working name is cleared. This text is a candidate description, not a published campaign.
